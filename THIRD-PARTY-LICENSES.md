# Third-Party Licenses

A summary of what dbt-temporal's dependencies are licensed under. The full
license texts ship with every release artifact (see
[In distributed artifacts](#in-distributed-artifacts)); always check the linked
sources for the current terms.

## dbt v2

[dbt v2](https://github.com/dbt-labs/dbt), the Rust rewrite of dbt developed in
the `dbt-labs/dbt` repository (formerly `dbt-labs/dbt-core`), is **Apache 2.0**
as of the pinned `v2.0.11` release. The workspace license applies to every crate
dbt-temporal consumes, including the bundled `minijinja` fork.

dbt Labs also ships its own distribution of dbt v2 with product-specific
additions under a separate product license (the
[dbt Fusion engine license agreement](https://www.getdbt.com/dbt-fusion-engine-license-agreement)).
dbt-temporal does not use that distribution — only the Apache 2.0 source.

Earlier Fusion preview releases in the separate
[dbt-fusion](https://github.com/dbt-labs/dbt-fusion) repository used a split
Apache 2.0 / Elastic License 2.0 (ELv2) model that restricted offering the
software as a hosted service. dbt-temporal no longer depends on that repository,
and none of the crates it links against are under the Elastic License — the
restriction does not apply to dbt-temporal binaries.

- License file: [dbt LICENSE](https://github.com/dbt-labs/dbt/blob/main/LICENSE)

## Temporal Rust SDK

The [Temporal Rust SDK](https://github.com/temporalio/sdk-rust), consumed as the
published `temporalio-*` crates, is **MIT-licensed** as of this writing.

- License file: [sdk-rust LICENSE.txt](https://github.com/temporalio/sdk-rust/blob/main/LICENSE.txt)

## Other dependencies

The rest of the dependency graph is permissively licensed — mostly Apache 2.0
and MIT, plus BSD, ISC, Zlib, Unicode and a few others — except for four crates
under the Mozilla Public License 2.0 (`im`, `sized-chunks`, `bitmaps`,
`option-ext`), a file-level copyleft that is met by pointing recipients at
their unmodified source on crates.io. The accepted licenses are listed in
[about.toml](about.toml); a dependency under anything else fails CI.

One crate needs care: **ring** splits its terms across files — ISC for its own
code, Apache 2.0 for code taken from BoringSSL. about.toml pins both files by
checksum so the bundle carries each text.

The project also pins forks of arrow-rs and ring maintained by
[sdf-labs](https://github.com/sdf-labs) and a fork of arrow-adbc maintained by
[dbt-labs](https://github.com/dbt-labs) for dbt v2 compatibility — the
forks retain the same licenses as their upstream projects.

## In distributed artifacts

Running dbt-temporal as a service is not distribution, but the release
packages, container images and Helm chart are, and the Apache 2.0 and MIT
licenses require their texts to travel with the copies. Each release artifact
carries `LICENSE` (this project, MIT) and, except for the chart, which contains
no third-party code, `THIRD-PARTY-LICENSES.txt`: the license text of every
crate compiled into the binary, generated by
[cargo-about](https://github.com/EmbarkStudios/cargo-about) from the release
build's dependency graph (`make licenses`).

| Artifact | Location |
|---|---|
| `.deb` | `/usr/share/doc/dbt-temporal/` |
| `.rpm` | `/usr/share/licenses/dbt-temporal/` |
| Container images | `/usr/share/doc/dbt-temporal/` |
| Helm chart | `LICENSE` at the chart root |
